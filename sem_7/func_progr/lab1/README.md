# Лабораторна робота №1 — варіант 3

Інформаційна система **«Програмне забезпечення на мережі факультету»** на Haskell з використанням
класів типів (`class` / `instance`) і бази даних MySQL.

## Можливості

- каталог програмних засобів: назва, автори, анотація, вид, версія, терміни та умови використання,
  місце збереження дистрибутива;
- пошук за назвою або текстом анотації, за автором, за видом, пошук ліцензій, що закінчуються;
- додавання, редагування й видалення програмних засобів;
- довідники видів, авторів і користувачів (список, додавання, редагування, видалення);
- реєстрація фактів використання та відгуків з оцінками;
- статистика: кількість запусків, кількість користувачів, сумарний час, середня оцінка, найактивніші користувачі.

## База даних (7 таблиць)

| Таблиця            | Зміст                                                            |
|--------------------|------------------------------------------------------------------|
| `categories`       | види програмних засобів                                          |
| `authors`          | автори (розробники)                                              |
| `software`         | програмні засоби: анотація, версія, дистрибутив, терміни, умови  |
| `software_authors` | зв'язок «багато до багатьох» між ПЗ і авторами                   |
| `users`            | користувачі: студенти, викладачі, співробітники                  |
| `usage_log`        | статистика використання: хто, що, коли, скільки хвилин           |
| `reviews`          | відгуки та оцінки (популярність)                                 |

## Класи типів

| Клас                         | Призначення                                                            | Екземпляри                                             |
|------------------------------|------------------------------------------------------------------------|--------------------------------------------------------|
| `Entity`                     | назва таблиці, колонки, ключ; узагальнені `fetchAll`, `fetchById`, `insertEntity`, `updateEntity`, `deleteEntity` | `Category`, `Author`, `Software`, `User`, `Usage`, `Review` |
| `Editable`                   | введення нового запису та редагування існуючого з клавіатури           | ті самі типи                                           |
| `Pretty`                     | текстове представлення запису                                          | усі типи + `SoftwareRow`                               |
| `QueryResults`, `QueryParams` (mysql-simple) | перетворення рядка таблиці в запис і запису в параметри запиту | усі типи                                          |

## Структура

```
schema.sql          створення бази faculty_software і тестові дані
app/Main.hs         меню
src/Types.hs        типи даних + екземпляри QueryResults / QueryParams
src/Entity.hs       клас Entity і узагальнені CRUD-операції
src/Editable.hs     клас Editable
src/Pretty.hs       клас Pretty
src/Search.hs       пошук і статистика
src/Input.hs        введення з клавіатури з перевіркою
src/Db.hs           підключення до MySQL
```

## Запуск

1. Встановити MySQL і бібліотеку клієнта (macOS: `brew install mysql pkg-config`).
2. Створити базу:
   ```
   mysql -u root -p < schema.sql
   ```
3. Зібрати й запустити:
   ```
   cabal update
   cabal run faculty-software
   ```
   Параметри підключення задаються змінними середовища (за замовчуванням `root` без пароля на `localhost:3306`):
   ```
   DB_USER=root DB_PASSWORD=secret cabal run faculty-software
   ```
   Доступні змінні: `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`.
