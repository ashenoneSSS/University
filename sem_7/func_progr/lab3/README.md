# Лабораторна робота №3 — варіант 6

Програма обробки тексту підручника з програмування на Haskell.

**Завдання:** надрукувати слова тексту в алфавітному порядку за першою літерою. Слова, що
починаються з нової літери, друкувати з червоного рядка. Табуляції та послідовності пробілів
замінюються одним пробілом.

## Типи

| Тип           | Значення                                                                 |
|---------------|--------------------------------------------------------------------------|
| `Symbol`      | символ: `Letter` (літера), `Digit` (цифра), `Joiner` (апостроф, дефіс усередині слова) |
| `Word`        | слово — послідовність символів                                           |
| `Punctuation` | розділовий знак                                                          |
| `Token`       | слово, число або розділовий знак                                         |
| `Sentence`    | речення — послідовність токенів до `.`, `!`, `?` або `…`                 |
| `Text`        | текст — послідовність речень                                             |

## Алгоритм

1. `normalizeSpaces` замінює табуляції, переноси рядків і серії пробілів одним пробілом.
2. `tokenize` розбиває рядок на слова, числа й розділові знаки. Апостроф і дефіс усередині слова
   (`об'єднує`, `будь-яке`) лишаються частиною слова.
3. `splitSentences` групує токени в речення.
4. `alphabeticalWords` бере всі слова, зводить до нижнього регістру, прибирає повтори й сортує
   за алфавітом. Порядок літер задано явно (модуль `Alphabet`): спочатку латиниця, далі українська
   абетка `а б в г ґ д е є ж з и і ї й … ю я`. Сортування за кодами Unicode тут не підходить: у
   ньому `є`, `і`, `ї`, `ґ` стоять після `я`.
5. `groupByInitial` групує слова за першою літерою. `formatParagraphs` друкує кожну групу як новий
   абзац з відступом (червоний рядок) і переносить довгі рядки на ширині 80 символів.

## Запуск

```
cabal run textbook-words -- textbook.txt
```

або

```
ghc -O2 -iapp -isrc app/Main.hs -o textbook-words
./textbook-words textbook.txt
```

Без аргументу читається файл `textbook.txt` у поточній папці.
